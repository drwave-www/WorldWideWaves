expect class SpriteCachePreferences(source)

Platform-specific storage for sprite cache state.

This interface abstracts persistent storage (SharedPreferences on Android, NSUserDefaults on iOS) for tracking sprite cache completion and versioning.

Purpose: Ensure sprite cache persists across app restarts and invalidates when app version changes.

actual class SpriteCachePreferences

iOS implementation of sprite cache preferences using NSUserDefaults.

Stores cache completion state and version in standard user defaults.

Version Format: "SHORT_VERSION+BUILD" (e.g., "1.0.0+42")
